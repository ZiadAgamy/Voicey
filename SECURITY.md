# Security Policy

If you find a security problem in Voicey (for example a way for a non-owner to control someone else's channel, or a way to leak the bot token), please **do not open a public issue**. Contact the maintainer privately first through the [support server](https://fluxer.gg/JHqdSzV4) or the contact details on the repository profile, and give them reasonable time to fix it.

## For people running Voicey

- Keep `.env` private and out of version control. If a token or webhook URL is ever exposed, regenerate it immediately.
- Run the bot with the minimum permissions listed in the README.
